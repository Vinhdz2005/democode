📋 Hướng dẫn cập nhật dữ liệu:

  1. Thay đổi thông tin bạn muốn trong các tab trên
  2. Bấm nút "Lưu dữ liệu" (màu xanh)
  3. Dữ liệu sẽ tự động được lưu vào file data.json
  4. Refresh trang chính để thấy thay đổi

Lưu ý: Cần chạy trên web server (localhost) để tính năng lưu tự động hoạt động.
